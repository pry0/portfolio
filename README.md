# Portfolio

Private investment workspace for https://portfolio.pry0.com/.

Standalone Cloudflare Worker and D1 application. No `/portfolio` route is added to Lab. Source code contains no financial records or credentials.

The first release provides accounts, reviewed CSV imports, preserved originals, a corporate-action register, free crypto and FX observations, and a feature planner. HL uses file imports initially; a live HL account connection has not been established.

Deployment and verification details are being added with the initial implementation.
